## 🚀 Featured Projects

### 🏛️ [Emergency Evacuation Simulation](https://github.com/Sidharthkris/emergency-evacuation-simulation)

> *Master's Thesis — TU Clausthal, 2025*

An **agent-based simulation** modelling how occupants evacuate university lecture halls under emergency conditions. Built in **NetLogo**, with statistical analysis carried out in Python.

**Highlights:**
- 🧑‍🤝‍🧑 Modelled heterogeneous agent behaviour (students, mobility-impaired individuals, instructors)
- 🚪 Evaluated multiple exit configurations and crowd density scenarios
- 📊 Identified bottleneck patterns and proposed layout recommendations grounded in simulation data
- 📈 Results visualised with Python (Pandas, Matplotlib)

**Key skills demonstrated:** Agent-based modelling · NetLogo · Simulation design · Statistical analysis · Python · Scientific writing
